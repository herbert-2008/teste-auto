Estudos de Cypress

Projeto desenvolvido para praticar automação de testes web com Cypress e JavaScript, aprendendo conceitos de Quality Engineering (QE).

 Objetivo

Aprender a criar testes automatizados, validar funcionalidades e identificar possíveis falhas em aplicações web.

Tecnologias
Cypress
JavaScript
Node.js
Git e GitHub
 Conteúdos estudados
Configuração do Cypress
Criação de testes E2E
Seletores e comandos
Validação de resultados (assertions)
Testes positivos e negativos
Fundamentos de QE, BDD e Gherkin
 Progresso

Projeto em desenvolvimento, com novos testes e aprendizados adicionados durante minha evolução na área de automação de testes.
